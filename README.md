# Simulating Weak Values in Quantum Computing (PennyLane Demo Proposal)

This repository contains a demonstration notebook for PennyLane showcasing how to simulate **weak measurements and weak values** in quantum computing.

- **Author:** S. Parra-San-Pedro
- **Reference Thesis (DOI):** [10.5281/zenodo.23195289](https://doi.org/10.5281/zenodo.23195289)

## File Overview
- `pennylane_weak_values.ipynb`: Main Jupyter Notebook containing the theoretical overview, PennyLane circuit implementation, and numerical results.

## Requirements & Dependencies
This notebook was built and tested with:
- `pennylane` (v0.45.1)
